# Poizon-parsing — сбор данных из приложения Dewu (得物 / Poizon)

[![tests](https://github.com/greg2377/Poizon-parsing/actions/workflows/tests.yml/badge.svg)](https://github.com/greg2377/Poizon-parsing/actions/workflows/tests.yml)
![license](https://img.shields.io/badge/license-MIT-blue)

> **English summary.** Free, open-source tool that drives the real Dewu (Poizon) mobile app on your own
> Android phone or iPhone via UI automation (uiautomator2 / Appium) and reads what the app shows on screen:
> product title, article number, brand, **price for every size**, delivery options and the **size chart**.
> It crawls a product list automatically, resumes after interruption and exports to CSV/Excel.
> It does **not** bypass request signing, SSL pinning or any anti-bot protection.
> Quick start: `pip install -r requirements-android.txt` → open a product list in the app →
> `python -m poizon crawl --platform android --max 5` → `python -m poizon export`. Docs below are in Russian.

Бесплатный инструмент, который **управляет настоящим приложением Dewu на вашем телефоне**
(как человек: открывает товар, листает, нажимает) и **читает то, что приложение показывает на экране**.
Для каждого товара он собирает:

- название, **артикул (货号)**, бренд и другие характеристики;
- цену для **каждого размера** (¥, юани) и отметку «нет в наличии»;
- варианты доставки (цена, срок, тип: 保税直发, 品牌官方 …);
- **размерную сетку** («尺码助手»: EU, пояснение, US, длина стопы в см; для одежды — свои колонки);
- время сбора и метку источника (категория/запрос).

Результат можно выгрузить в **Excel/CSV**, по строке на каждый размер, с пересчётом в рубли.

> **Статус.** Логика разбора и обхода покрыта тестами (на текстах с реальных скриншотов и на симуляции экранов),
> но **на живом телефоне ещё не проверялась**. На первом запуске возможны правки — см. «Если что-то не работает»
> и присылайте дампы экрана (раздел 10).

## 1. Как это работает

Dewu защищает свой API подписью запросов, поэтому «чистый» парсинг сервера не вариант.
Здесь другой подход — **автоматизация интерфейса**:

```
python -m poizon ──► uiautomator2 (Android)  или  Appium + WebDriverAgent (iPhone) ──► приложение Dewu
       ▲                                                                                   │
       └──────────── тексты с экрана (название, ¥цены, таблица размеров, 货号) ◄────────────┘
```

1. Приложение само делает все свои запросы и само их подписывает.
2. Инструмент получает дерево элементов экрана и вытаскивает из него тексты.
3. Парсеры (`poizon/parse.py`) превращают тексты в данные.
4. Обход (`crawl`) делает это для каждого товара в открытом списке и сохраняет результат построчно.

Что инструмент нажимает: карточку товара, кнопку «立即购买» (**только чтобы открыть список размеров**),
ссылку на размерную сетку, кнопки закрытия всплывающих окон («我知道了», «关闭» …), «Назад», прокрутку.
**Размер он не выбирает, заказ не оформляет и ничего не оплачивает.**

## 2. Чего инструмент НЕ делает

- Не обходит защиту Dewu: не подделывает подпись запросов, не снимает SSL-pinning, не маскирует устройство или автоматизацию, не решает капчи.
- Не получает данные «в обход» приложения: видно только то, что приложение показывает вашему аккаунту.
- Не работает без телефона с установленным Dewu и вашим входом.

## 3. Быстрый старт

| Есть | Что делать |
|---|---|
| Android-телефон и любой компьютер (Windows / macOS / Linux) | раздел 4 — самый простой путь |
| iPhone и Mac | разделы 5–6 |
| iPhone без Mac | пока не поддерживается: нужен Mac (хотя бы один раз для подписи) или Android-телефон |

Общий порядок для любой платформы:

1. **Проверка на одном товаре:** откройте товар в приложении → `python -m poizon item --platform …`.
2. **Обход списка:** откройте категорию/поиск → `python -m poizon crawl --platform … --max 5`.
3. **Выгрузка:** `python -m poizon export --rate 12.5` → `out/products.xlsx`.

## 4. Android: установка и запуск

Работает на **Windows, macOS и Linux** — Mac не нужен. Нужен Android-телефон
(лучше реальный: на эмуляторах приложение может не запускаться или вести себя иначе).

### 4.1. Подготовка компьютера

1. Установите **Python 3.9+** (python.org; на Windows при установке отметьте «Add Python to PATH»).
2. Установите **ADB** (Android Platform Tools):
   - Windows: скачайте «SDK Platform-Tools for Windows» с developer.android.com/tools/releases/platform-tools, распакуйте, добавьте папку в PATH.
   - macOS: `brew install android-platform-tools`
   - Linux (Debian/Ubuntu): `sudo apt install adb`

   Проверка: `adb version`.
3. Скачайте проект и поставьте зависимости:

```bash
git clone https://github.com/greg2377/Poizon-parsing.git
cd Poizon-parsing-
python -m venv .venv
# Windows:  .venv\Scripts\activate          macOS/Linux:  source .venv/bin/activate
pip install -r requirements-android.txt
```

### 4.2. Подготовка телефона

1. Настройки → О телефоне → **7 раз нажмите «Номер сборки»** (Xiaomi — «Версия MIUI/HyperOS»). Появится «Вы стали разработчиком».
2. Настройки → Система (или «Дополнительно») → Для разработчиков → включите **Отладка по USB**.
   - Xiaomi/Redmi/Poco: дополнительно «Установка через USB» и «Отладка по USB (настройки безопасности)».
   - Другие марки: пункты называются похоже; ищите «Для разработчиков» в поиске настроек.
3. Подключите телефон кабелем (кабель для данных, не только зарядный) и **разрешите отладку** в окне на телефоне
   («Всегда разрешать с этого компьютера»).
4. Проверьте: `adb devices` — телефон в списке со статусом `device` (не `unauthorized`/`offline`).
5. Установите Dewu (得物), войдите в аккаунт. Рекомендуется: время до отключения экрана — максимум.
6. Один раз: `python -m uiautomator2 init` (на телефон ставится служебное приложение; разрешите установку, если спросит).

### 4.3. Запуск

```bash
# 1) один товар: откройте страницу товара в Dewu, затем
python -m poizon item --platform android

# 2) обход списка: откройте категорию / бренд / поиск с карточками «¥…», затем
python -m poizon crawl --platform android --max 5 --source "ботинки Timberland"

# 3) выгрузка в Excel/CSV (курс юаня к рублю — по желанию)
python -m poizon export --rate 12.5
```

Если подключено несколько устройств, добавьте `--serial <ID из adb devices>`.

## 5. iPhone: установка (нужен Mac)

**Что нужно:** Mac, iPhone с установленным и авторизованным Dewu, USB-кабель, Apple ID (бесплатного хватает).

### 5.1. Инструменты на Mac

Откройте «Терминал» и выполните по порядку:

```bash
# 1) Xcode — установите из App Store, один раз запустите и примите лицензию:
sudo xcodebuild -license accept
xcode-select --install            # command line tools (если ещё не стоят)

# 2) Homebrew (если нет): https://brew.sh
brew install node libimobiledevice ideviceinstaller python

# 3) Appium и драйвер для iOS
npm install -g appium
appium driver install xcuitest
appium driver doctor xcuitest     # покажет, чего ещё не хватает
```

### 5.2. Подготовка iPhone

1. Подключите iPhone по USB, разблокируйте, нажмите «Доверять этому компьютеру».
2. **Режим разработчика:** Настройки → Конфиденциальность и безопасность → Режим разработчика → включить; телефон перезагрузится, подтвердите.
3. Установите Dewu из App Store, войдите в аккаунт.
4. Рекомендуется: Настройки → Экран и яркость → Автоблокировка → «Никогда» (на время работы).

### 5.3. UDID телефона и bundle id приложения

```bash
idevice_id -l                                              # UDID телефона
ideviceinstaller -l | grep -i -E "dewu|得物|siwu|duapp"    # bundle id приложения
```

По умолчанию используется `com.siwuai.duapp` — это **неподтверждённое** значение. Если ваш отличается,
передавайте `--bundle-id <значение>`.

### 5.4. Подписать WebDriverAgent (самое «капризное» место)

Appium ставит на iPhone служебное приложение WebDriverAgent (WDA); его нужно подписать вашим Apple ID.
Выберите **один** способ.

**Способ А — через Xcode (надёжнее):**

1. Откройте проект
   `~/.appium/node_modules/appium-xcuitest-driver/node_modules/appium-webdriveragent/WebDriverAgent.xcodeproj`
   (если не найдёте: `find ~/.appium -name WebDriverAgent.xcodeproj`).
2. Xcode → Settings → Accounts → добавьте свой Apple ID.
3. Слева проект → таргет **WebDriverAgentRunner** → Signing & Capabilities: отметьте Automatically manage signing,
   выберите свой **Team**, в **Bundle Identifier** впишите уникальное значение, например `com.ВАШ_НИК.WebDriverAgentRunner`.
4. То же для таргета **IntegrationApp** (если Xcode ругается).
5. Выберите iPhone как устройство → Product → Test (⌘U) один раз: WDA установится на телефон.
6. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».

**Способ Б — автоматически через Appium:** узнайте свой Team ID (10 символов; Xcode → Settings → Accounts)
и добавляйте к командам `--team-id ВАШ_TEAM_ID --wda-bundle-id com.ВАШ_НИК.wda`.

> С бесплатным Apple ID подпись **действует 7 дней**: потом повторите шаг 5.4.5.

### 5.5. Python-окружение

```bash

source .venv/bin/activate

В **первом** окне терминала запустите Appium и оставьте его работать:

```

Во **втором** окне (с активированным `.venv`):

## 7. Все команды и параметры

```
python -m poizon item    --platform android|ios [устройство] [тексты] [--out out/item.json]
python -m poizon crawl   --platform android|ios [устройство] [тексты] [--max N] [--break-every N] [--source ТЕКСТ] [--out out/products.jsonl]
python -m poizon dump    --platform android|ios [устройство] [--out out/screen]
python -m poizon export  [--in out/products.jsonl] [--out out/products] [--rate КУРС]
```

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `--platform` | — (обязателен) | `android` или `ios` |
| `--serial` | — | Android: ID устройства из `adb devices`, если их несколько |
| `--udid` | — | iOS: UDID телефона (обязателен для iOS) |
| `--bundle-id` | `com.siwuai.duapp` | iOS: bundle id Dewu |
| `--team-id`, `--wda-bundle-id` | — | iOS: автоподпись WDA (способ Б) |
| `--server` | `http://127.0.0.1:4723` | iOS: адрес Appium |
| `--buy-text` | `立即购买` | текст кнопки, открывающей список размеров |
| `--chart-text` | `尺码推荐` | текст ссылки на «尺码助手» (не подтверждён — см. раздел 9) |
| `--max` | 200 | сколько товаров собрать за запуск |
| `--break-every` | 30 | пауза 30–90 с после каждых N товаров (0 — выключить) |
| `--source` | — | метка, сохраняемая с каждым товаром (категория, запрос) |
| `--rate` | — | курс CNY→RUB; добавляет колонку `price_rub` |

**Как устроен обход (`crawl`):**

1. Закрывает известные всплывающие окна, находит на экране карточки по тексту цены «¥…».
2. Нажимает первую ещё не обработанную. **Проверяет, что открылась страница товара** (есть «立即购买»);
   если нет (баннер, реклама) — сохраняет скриншот в `out/errors/`, возвращается и идёт дальше.
3. Читает название, листает вниз до «商品信息» за артикулом и брендом, открывает список размеров и таблицу размеров.
4. Возвращается к списку. Если список не найден — **останавливается** (чтобы не бродить по приложению).
5. Товар с уже собранным артикулом не записывается повторно. После 3 ошибок подряд обход останавливается.
6. Каждый товар **сразу** дописывается в `out/products.jsonl`. Повторный запуск **продолжает**: уже обработанные карточки пропускаются.

## 8. Что получится на выходе и выгрузка в Excel

`out/products.jsonl` — одна строка JSON на товар. Пример (данные с реальных скриншотов, сокращено):

```json
{
  "scraped_at": "2026-10-07T10:05:00+00:00",
  "source": "ботинки Timberland",
  "title": "Timberland添柏岚 Martin 舒适防水 短筒 户外靴 男款 小麦色 宽版",
  "article": "10061",
  "brand": "Timberland",
  "sizes": [
    {"size": "39.5", "hint": "建议买小一码", "price_cny": 628.0, "available": true},
    {"size": "43.5", "hint": "建议买小一码", "price_cny": 512.0, "available": true},
    {"size": "47",   "hint": "",             "price_cny": null,  "available": false}
  ],
  "delivery": [
    {"price_cny": 512.77, "eta": "约1-3天到", "labels": ["已含税", "保税直发"]},
    {"price_cny": 799.0,  "eta": "约4-5天到", "labels": ["顺丰速运", "品牌官方"]}
  ],
  "size_chart": {
    "columns": ["eu", "note", "us", "foot_cm"],
    "rows": [
      {"eu": "39.5", "note": "建议买小一码", "us": "6.5", "foot_cm": "24.5"},
      {"eu": "46",   "note": "建议买小一码", "us": "12",  "foot_cm": "30"}
    ]
  },
  "card_key": "…внутренний ключ карточки…"
}
```

Пояснения: `price_cny` — цена в юанях для этого размера; `available: false` — размера нет в наличии;
`hint` «建议买小一码» = «берите на размер меньше»; `foot_cm` — рекомендуемая длина стопы (бывает диапазоном «25-25.5»);
`delivery` — варианты доставки с листа размеров; `article` — артикул (货号) производителя.

**Выгрузка:** `python -m poizon export --rate 12.5` создаёт `out/products.csv` и `out/products.xlsx` —
**одна строка на пару «товар + размер»**: дата, источник, артикул, бренд, название, размер, пометка, наличие,
цена в юанях, цена в рублях (если указан `--rate`) и колонки размерной сетки для этого размера (`chart_us`, `chart_foot_cm` …).
CSV сохраняется в кодировке, которую Excel открывает с китайскими символами без «кракозябр».

## 9. Если что-то не работает

Первое, что стоит сделать при любой проблеме: открыть нужный экран и выполнить
`python -m poizon dump --platform …` — появятся `out/screen.png` и `out/screen.xml`. При ошибках обхода смотрите `out/errors/`.

**Общие:**

| Симптом | Что делать |
|---|---|
| `title: null`, нет `sizes` | Приложение может рисовать текст не стандартными элементами. Пришлите `out/screen.xml` + `out/screen.png` (раздел 10) |
| Нет `article`/`brand` | Блок «商品信息» дальше 4 прокруток или подписи другие. Пришлите дамп экрана с этим блоком |
| Таблица размеров не открывается | Ссылка называется иначе: посмотрите текст на экране листа размеров и передайте `--chart-text "<текст>"` |
| Обход: «not a product page» на каждой карточке | Кнопка покупки называется иначе: `--buy-text "<текст>"`, либо пришлите дамп страницы товара |
| Обход не находит карточки | Пришлите дамп экрана списка: правила поиска карточек — `android_cards` / `ios_cards` в `poizon/devices.py` |
| «list screen not found after going back» | «Назад» не вернул к списку; пришлите вывод и файлы из `out/errors/` |
| Застревает на всплывающем окне | Пришлите скриншот: добавим текст кнопки в `POPUP_CLOSE_TEXTS` (`poizon/parse.py`) |
| Приложение показывает капчу, блокирует вход | **Остановитесь.** Это защита сервиса; инструмент её не обходит и не будет обходить |

**Android:**

| Симптом | Что делать |
|---|---|
| `adb devices` пусто или `unauthorized` | Другой кабель/порт; на телефоне «Отозвать авторизации отладки по USB» и разрешить заново |
| `adb devices` → `offline` | `adb kill-server && adb start-server`, переподключить кабель |
| Ошибка `uiautomator2 init` / не ставится apk | Xiaomi: включить «Установка через USB»; разрешить установку из неизвестных источников |

**iPhone:**

| Симптом | Что делать |
|---|---|
| Appium пишет, что нет драйвера/зависимостей | `appium driver doctor xcuitest` и выполните то, что он просит |
| `xcodebuild failed with code 65` / ошибка подписи | Повторите 5.4: Team и уникальный Bundle Identifier; «Доверять» на iPhone |
| `Could not find a connected iOS device` | Разблокируйте телефон, «Доверять», проверьте `idevice_id -l` |
| Приложение не запускается | Проверьте bundle id (5.3) и передайте `--bundle-id` |
| Через неделю перестало работать | Истекла 7-дневная подпись бесплатного Apple ID: повторите 5.4.5 |
| Лист размеров не закрывается | Пришлите скриншот и вывод: закрытие сделано нажатием в верхнюю затемнённую область |

## 10. Участие в проекте

Проект открытый, помощь приветствуется — автор не может проверить все телефоны и версии приложения.

- **Сообщить о проблеме:** создайте issue по шаблону «Парсер не сработал» и приложите `out/screen.xml` + `out/screen.png`
  (или файлы из `out/errors/`). **Перед отправкой уберите личные данные:** имя, адрес доставки, телефон, номер заказа.
- **Исправить код:** правьте парсер (`poizon/parse.py`) или правила поиска карточек (`poizon/devices.py`),
  добавьте тест с текстами экрана в `tests/` и пришлите pull request.
- **Рассказать, что работает:** модель телефона, версия Dewu, платформа — это тоже ценно.

Изменения, которые обходят защиту Dewu (подделка подписи, снятие SSL-pinning, маскировка устройства), не принимаются.

## 11. Для разработчиков

```
poizon/
  parse.py      парсеры экранов: название, характеристики, размеры, доставка, размерная сетка, всплывающие окна
  devices.py    адаптеры AndroidDevice (uiautomator2) и IOSDevice (Appium) + поиск карточек в дереве экрана
  crawler.py    общая логика: scrape_item (один товар) и crawl (обход списка, возобновление, диагностика)
  export.py     products.jsonl → CSV/XLSX
  __main__.py   командная строка
tests/          тесты: тексты с реальных скриншотов и симуляция экранов приложения (FakeDevice)
```

Тесты не требуют телефона:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Они же запускаются в GitHub Actions на каждый push и pull request (Python 3.9, 3.12, 3.13).
Вся платформенная специфика — в `poizon/devices.py`; новый адаптер должен реализовать тот же небольшой интерфейс
(`texts`, `cards`, `tap_text`, `tap`, `scroll_down`, `back`, `close_sheet`, `screenshot`, `source`, `has_text`).

## 12. Риски и ограничения

- **Условия Dewu**, скорее всего, запрещают автоматический сбор данных. Используйте на свой риск.
- **Блокировка аккаунта** возможна. Паузы снижают нагрузку, но не исключают блокировку. Начинайте с малого и на отдельном аккаунте.
- **Нагрузка:** не ставьте огромные `--max` и не отключайте паузы.
- **Скорость:** обход «как человек» — порядка 20–40 секунд на товар; тысячи товаров — это много часов.
- **Нестабильность:** обновление приложения может изменить экраны; тогда нужно подправить тексты (`--buy-text`, `--chart-text`) или парсеры.
- **Данные** — только то, что приложение показывает вашему аккаунту (регион, цены и наличие зависят от аккаунта и времени).
